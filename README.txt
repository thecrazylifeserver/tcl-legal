THE CRAZY LIFE - DISCORD BOT LEGAL SITE

WICHTIG: terms.html und privacy.html sind Vorlagen. Alle [Platzhalter] vor Veröffentlichung anhand der tatsächlichen Bot-Funktionen ergänzen und rechtlich prüfen.

GitHub Pages Setup:
1) Auf github.com anmelden und neues PUBLIC Repository 'tcl-legal' erstellen.
2) index.html, terms.html, privacy.html und style.css INS STAMMVERZEICHNIS des Repository hochladen (nicht in einem Unterordner).
3) Repository -> Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /(root) -> Save.
4) Nach Veröffentlichung lauten die Adressen:
   https://DEIN-GITHUB-NAME.github.io/tcl-legal/terms.html
   https://DEIN-GITHUB-NAME.github.io/tcl-legal/privacy.html
5) Diese Adressen in Discord Developer Portal unter Terms of Service URL und Privacy Policy URL hinterlegen.

Hinweis: Der GitHub-Accountname steht in der URL; alle Inhalte des öffentlichen Repository sind öffentlich. Keine Passwörter, Schlüssel oder personenbezogene Zugangsdaten hochladen.
